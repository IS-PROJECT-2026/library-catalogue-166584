# Library Catalogue System

A responsive web application designed to manage, browse, and filter library book inventories efficiently. Built as part of the Mini-Project Git Workflow Challenge.

## Live Demo
* **GitHub Pages Deployment:** [View Live Site](https://DelightW.github.io/library-catalogue-166584/)

## Technologies Used
* **HTML5:** Semantic markup structure for accessibility and layout organization.
* **CSS3:** Modern styling featuring Flexbox, CSS Grid, and responsive design media queries.
* **Vanilla JavaScript (ES6+):** Dynamic DOM manipulation, array filtering, and reactive component rendering.
* **Git & GitHub:** Version control, branch protection workflows, and Kanban project management.

## Features
* **Dynamic Book Grid:** Automatically renders book cards with cover details, categories, and real-time availability status.
* **Interactive Catalogue:** Filter and search capabilities for quick book discovery.
* **Responsive Layout:** Optimized for both mobile and desktop viewports.
